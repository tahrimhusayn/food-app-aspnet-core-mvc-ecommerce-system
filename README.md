# 🍔 Food App – ASP.NET Core MVC E-Commerce System

## 📌 Project Overview

Food App is a full-stack ASP.NET Core MVC e-commerce web application designed for online food ordering with a complete role-based system including Admin, Seller, and Customer functionalities.

The system provides a real-world food ordering experience with product browsing, cart management, order processing, and dashboard-based management for different user roles.

---

## 🚀 Features

### 🔐 Authentication System

- User Registration (Signup)
- User Login & Logout
- ASP.NET Identity Integration
- Role-Based Authorization (Admin, Seller, Customer)
- Secure session-based authentication

---

### 👤 Role-Based Access Control

#### 👨‍💼 Admin

- Access Admin Dashboard
- Manage users (customers & sellers)
- Manage all products
- Manage categories
- Manage orders
- Full system control

#### 🧑‍💼 Seller

- Access Seller Dashboard
- Create, edit, delete own products
- Manage stock and product details
- View seller-related orders

#### 👤 Customer

- Browse food products
- View product details
- Add products to cart
- Update/remove cart items
- Place orders
- View order history
